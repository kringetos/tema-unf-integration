# Исходные материалы и исключения

## Включено

- Исходники Python API и тестовой формы из `integrations/tema_api`.
- XML/BSL-исходники расширения `TEMA_API`.
- Unit-тесты `tests/test_tema_api.py`.
- Шрифты Ubuntu, необходимые генератору спецификации, и их лицензия.
- Документация контракта, архитектуры и известных ограничений, составленная по
  коду и сохранённому описанию проверок.

## Не включено

- Athena, её UI, ассеты кроме двух необходимых шрифтов, окружение и зависимости.
- `settings.json`, токен API, пароли 1С, локальные журналы, SQLite-журнал,
  резервные копии публикации, PDF/PNG фактических тестовых документов, база `.1CD`
  и собранный `.cfe`.
- Репозиторий `1c-oData-skill-main`: это самостоятельный проект с собственным
  окружением и настройками. Для исследования OData использовался локальный путь
  `C:\Users\Kring\Desktop\1c-oData-skill-main`; в новый проект не копировались
  его конфигурации, виртуальная среда или серверы.
- Исходный PDF `API Интеграция 1с (1).pdf`: на момент сборки файл отсутствует
  по прежнему адресу в Downloads. Основные известные требования и неоднозначности
  контракта сохранены в документации и комментариях реализации, но оригинал PDF
  нужно добавить вручную, если он понадобится как неизменённый источник.
- Исходники старого amoCRM-виджета из `Documents1C.rar`: в архивной версии был
  вшит постоянный токен, задан прямой адрес другого API, а готовый `widget.zip`
  был старой сборкой. Не переносил эти небезопасные артефакты в проект; интеграция
  с виджетом помечена как незавершённая.
