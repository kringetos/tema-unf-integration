# Проверки

## Локальные unit-тесты

Тесты используют фиктивные OData/HTTP-объекты и не требуют подключения к базе:

```powershell
python -m unittest discover -s tests -v
```

Они проверяют сериализацию/экранирование OData v3, проверки маршрутов и тел,
преобразования значений УНФ, идемпотентность, авторизацию и передачу операций
в mock bridge. Они не доказывают, что конкретная версия УНФ проведёт документ.

## Проверка в тестовой базе

Проверяйте отдельно чтение/запись справочников, заказ, счёт, акт, PDF, контакты,
оплату, проведение, повтор с тем же `Idempotency-Key`, фильтры и неоднозначные
номера. Создавайте тестовые записи только в тестовой базе. Сверяйте результат
чтением из OData/1С после каждого изменения.

`GET /health` подтверждает только работу процесса Python. Для диагностики используйте
тестовую форму `/test`, но не размещайте её на публичном адресе без защиты.
